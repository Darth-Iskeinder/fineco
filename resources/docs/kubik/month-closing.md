# Закрытие месяца

*Актуально на 10 ноября 2026.*

Страница отвечает на один вопрос: закрыт ли месяц каждого клиента. Руководитель видит это по всей фирме и по каждому главбуху сразу, без обхода задач по одной.

## Какие задачи относятся к месяцу

Все задачи по смете, которые выпали на октябрь, это работа за сентябрь. Поэтому сентябрь клиента закрывают в октябре: в клетке «Сентябрь» стоят задачи со сроком в октябре.

Учитываются только задачи из сметы. Внеплановые задачи в расчёт не идут.

## Когда месяц закрыт

Месяц клиента закрыт, когда выполнено всё сразу:

- все сметные задачи месяца приняты. Задача «на проверке» ещё не закрыта: главбух с работой пока не согласился;
- у автоаудита нет вопросов, которые ждут бухгалтера или руководителя. Это условие есть только у фирм, где руководителю открыта страница автоаудита. У остальных в карточке написано, что автоаудит не включён и на закрытие не влияет.

Отчёты и налоги отдельно не проверяются. Пока не размечено, какие бизнес-процессы считаются отчётами, а факт оплаты налога система не фиксирует. Поэтому отчёты и оплата налогов входят в закрытие как обычные сметные задачи: не закрыта задача, не закрыт и месяц.

Ручной аудит к закрытию месяца пока не подключён: модуль в разработке. В карточке он показан серым с этой пометкой.

Сейчас «закрыт» значит «закрыт на сегодня». Если задачу переоткроют, месяц снова станет открытым.

## Срок закрытия

Пока срок закрытия месяца равен самому позднему сроку среди его задач. Если последняя задача за сентябрь стоит на 30 октября, сентябрь надо закрыть к 30 октября. Срок виден в карточке клиента.

## Что на странице

**Чипы по главбухам.** «Все» и по одному на каждого главбуха. Главбух здесь тот, кто записан ответственным в карточке клиента. Чип оставляет в таблице только его клиентов.

**Плитки.** Сколько клиентов закрыли выбранный месяц: по всей фирме и по каждому главбуху. Считаются только клиенты, у которых в этом месяце есть задачи. Месяц выбирается стрелками справа вверху. По умолчанию показан позапрошлый месяц: его задачи уже прошли, итог виден. Прошлый месяц ещё закрывают.

**Таблица клиенты × месяцы.** Шесть месяцев. В клетке одно из состояний:

- зелёная с галочкой: месяц закрыт;
- красная с крестиком: срок закрытия прошёл, а месяц не закрыт;
- пунктир: месяц ещё закрывают, срок впереди;
- точка без рамки: в этом месяце у клиента нет задач по смете.

**Карточка клиента.** Открывается по клику на клетку. В ней срок закрытия, какие сметные задачи не закрыты (кто исполнитель, где задача, какой срок), состояние автоаудита и пометка про ручной аудит.

## Кто видит страницу

Страница включается для фирмы отдельно, её видит руководитель. Бухгалтеры и главбухи её пока не видят.

## Чего пока нет

Страница пока не помнит, когда месяц закрылся. Поэтому нет «закрыт вовремя» и «закрыт с опозданием», нет процента вовремя закрытых месяцев и пометки о передаче клиента от одного главбуха другому. Нет и отдельных строк «отчёты сданы» и «налоги оплачены». Это следующие шаги.
